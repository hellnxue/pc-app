# PC管理系统

基于Vue 2 + Element UI的管理系统，使用Vue CLI 4.1.0搭建。

## 功能
- 用户登录
- 仪表板
- 用户管理
- 订单管理

## 技术栈
- Vue 2.6.11
- Element UI 2.15.6
- Vue Router 3.2.0
- Vuex 3.4.0
- ESLint 5.16.0
- babel-eslint 10.0.1

## 项目设置
```
npm install
```

### 开发环境编译和热重载
```
npm run serve
```

### 生产环境编译和压缩
```
npm run build
```

### 代码检查和修复
```
npm run lint
```

### 自定义配置
查看 [Configuration Reference](https://cli.vuejs.org/config/)。
